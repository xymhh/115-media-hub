## 结论

- 镜像：`ghcr.io/xymhh/115-media-hub:latest`（同时打 `0.15.11` 与 `sha-<短sha>` 标签）
- 构建：GitHub Actions `Build and publish image`（`.github/workflows/docker-publish.yml`，push 到 `main` 自动触发）
- 包可见性：**必须手动设为 Public**（GHCR 包默认私有，且 fork 仓库的 Settings 里没有这个开关）
  路径：`https://github.com/users/xymhh/packages/container/115-media-hub/settings` → Danger Zone → Change visibility
- 服务器：`/opt/1panel/apps/115-media-hub/docker-compose.yml`，容器 `115-media-hub`，网络 `1panel-network`（与 MP 同网，172.18.0.11），无宿主端口

## 部署方式

```bash
# 1Panel 上用 compose 操作；宿主机直接操作时等价于：
cd /opt/1panel/apps/115-media-hub && docker compose pull && docker compose up -d
```

数据卷：`./data/{config,strm,logs,storage}` → `/app/{config,strm,logs,storage}`。
